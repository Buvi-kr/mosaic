📋 기능 요약

모자이크 타일 위에 원본 사진을 얼마나 겹쳐 보여줄지 결정합니다.

⚙️ 동작 원리

  • 0% = 순수 모자이크만 보임 (원본 윤곽 없음)
  • 50% = 타일을 배경으로 원본 사진이 반투명하게 섞임
  • 100% = 블렌드 모드 효과 100% 적용 (※ Over 모드일 때만 원본 사진으로 완전히 덮어씌워지고, Multiply나 Overlay 등에서는 모자이크와 원본이 진하게 합성되어 보입니다.)
  • 서버에서 sharp 라이브러리의 Alpha 채널 합성으로 처리됨
💡 권장값 — 전시용: 50~70% (타일+얼굴 윤곽 균형) / 포토존용: 30~40% (모자이크 느낌 극대화)

어떤 방식으로 원본 사진과 모자이크를 섞을지 결정합니다.

▶ 상세 설명 보기

📋 기능 요약

원본 사진과 모자이크 타일 이미지를 합성할 때 사용하는 색상 혼합 알고리즘입니다.

🎨 각 모드 상세

  • Multiply (곱하기) — 두 이미지의 색상값을 곱합니다. 어두운 부분은 더 어두워지고 밝은 부분은 유지됩니다. 어두운 배경/머리카락 등에서 윤곽이 뚜렷해지는 효과.
    → 추천: 얼굴 인식이 중요한 전시
  • Overlay (오버레이) — 밝은 영역은 더 밝게, 어두운 영역은 더 어둡게 처리하여 전체적인 대비(contrast)를 높입니다.
    → 추천: 선명하고 생동감 있는 결과물을 원할 때
  • Soft-Light (부드러운 빛) — Overlay와 유사하지만 효과가 절반 정도로 부드럽습니다. 가장 자연스러운 합성 결과를 만듭니다.
    → 추천: 가장 무난하고 자연스러운 선택
  • Over (단순 덮어쓰기) — 블렌딩 계산 없이 원본을 단순히 투명도만큼 겹칩니다.
    → 추천: 투명도(Opacity)만으로 간단히 조절하고 싶을 때

Multiply 모드 전용 옵션입니다. 1차 그림자 합성 후, 모자이크 위에 원본 사진의 밝은 피부색과 눈동자를 살리기 위해 옅게(권장 20~40%) 한 번 더 덮어씁니다.

숫자가 작을수록 모자이크가 조밀해지며, 클수록 타일 속 사진이 잘 보입니다. (권장: 15~30)

📋 기능 요약

개별 모자이크 조각의 크기(가로×세로 정사각형 픽셀 수)를 결정합니다.

⚙️ 동작 원리

  • 값이 작을수록 (10~15px) — 타일 수가 기하급수적으로 증가 (예: 1080p에서 ~7,000장 이상). 처리 시간·RAM 사용량 증가. 모자이크가 매우 조밀해져 멀리서 보면 원본처럼 보임. 개별 타일 속 사진은 거의 안 보임.
  • 값이 클수록 (40~60px) — 타일 수 감소 (예: 1080p에서 ~500장). 빠른 처리·낮은 리소스. 개별 타일 속 사진이 선명하게 보이지만 모자이크 해상도가 낮아 얼굴 인식이 어려움.
💡 권장값 — 일반 전시: 20px (기본, 밸런스) / 대형 스크린(55"+): 15~18px / 근접 관람: 25~35px (가까이서 개별 사진 감상 가능)
⚠️ 타일 크기 변경 시 서버의 RAM 캐시가 자동 재구성됩니다. 저사양 PC에서는 20px 이상 권장.

업로드된 사진의 가로/세로 중 긴 쪽의 최대 길이를 제한합니다. (메모리 부족 방지용)

📋 기능 요약

업로드된 사진의 최종 모자이크 출력물 크기(긴 변 기준)를 제한합니다. 원본 크기와 관계없이 이 값 기준으로 비율을 유지한 채 리사이즈 후 모자이크를 생성합니다.

📐 각 옵션 상세

  • 1080px (FHD급) — 가장 빠른 처리. 일반 모니터/TV 출력에 적합. 예상 타일 수: ~2,900장 (20px 기준)
  • 1440px (QHD급, 권장) — 처리 속도와 품질의 균형. 대형 모니터에도 충분한 선명도. 예상 타일 수: ~5,200장 (20px 기준)
  • 1920px (4K 전 단계) — 고화질 출력. 대형 전시 디스플레이에 적합. 예상 타일 수: ~9,200장 (20px 기준). 처리 시간 증가.
  • 2560px (초고화질) — 최고 품질. 대형 LED 월 등 초고해상도 디스플레이 전용. 예상 타일 수: ~16,000장 (20px 기준). RAM 2GB+ 권장.
⚠️ 해상도가 높을수록 처리 시간·메모리 사용량이 비례 증가합니다. 동시 접속자가 많은 환경에서는 1440px 이하 권장.

같은 타일이 전체 모자이크에서 최대 몇 번까지 반복 사용될 수 있는지 제한합니다.

현재 칸 주변 N칸 범위 내에서 동일하거나 시각적으로 유사한 타일 배치를 금지합니다. 클수록 다양하지만 색상 정확도가 약간 떨어질 수 있습니다.
