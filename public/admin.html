📋 기능 요약

모자이크 타일 위에 원본 사진을 얼마나 겹쳐 보여줄지 결정합니다.

⚙️ 동작 원리

  • 0% = 순수 모자이크만 보임 (원본 윤곽 없음)
  • 50% = 타일을 배경으로 원본 사진이 반투명하게 섞임
  • 100% = 블렌드 모드 효과 100% 적용 (※ Over 모드일 때만 원본 사진으로 완전히 덮어씌워지고, Multiply나 Overlay 등에서는 모자이크와 원본이 진하게 합성되어 보입니다.)
  • 서버에서 sharp 라이브러리의 Alpha 채널 합성으로 처리됨
💡 권장값 — 전시용: 50~70% (타일+얼굴 윤곽 균형) / 포토존용: 30~40% (모자이크 느낌 극대화)

어떤 방식으로 원본 사진과 모자이크를 섞을지 결정합니다.

📋 기능 요약

원본 사진과 모자이크 타일 이미지를 합성할 때 사용하는 색상 혼합 알고리즘입니다.

🎨 각 모드 상세

  • Multiply (곱하기) — 두 이미지의 색상값을 곱합니다. 어두운 부분은 더 어두워지고 밝은 부분은 유지됩니다. 어두운 배경/머리카락 등에서 윤곽이 뚜렷해지는 효과.
    → 추천: 얼굴 인식이 중요한 전시
  • Overlay (오버레이) — 밝은 영역은 더 밝게, 어두운 영역은 더 어둡게 처리하여 전체적인 대비(contrast)를 높입니다.
    → 추천: 선명하고 생동감 있는 결과물을 원할 때
  • Soft-Light (부드러운 빛) — Overlay와 유사하지만 효과가 절반 정도로 부드럽습니다. 가장 자연스러운 합성 결과를 만듭니다.
    → 추천: 가장 무난하고 자연스러운 선택
  • Over (단순 덮어쓰기) — 블렌딩 계산 없이 원본을 단순히 투명도만큼 겹칩니다.
    → 추천: 투명도(Opacity)만으로 간단히 조절하고 싶을 때

Multiply 모드 전용 옵션입니다. 1차 그림자 합성 후, 모자이크 위에 원본 사진의 밝은 피부색과 눈동자를 살리기 위해 옅게(권장 20~40%) 한 번 더 덮어씁니다.

숫자가 작을수록 가로/세로 칸수가 폭발적으로 증가하여 모자이크가 엄청나게 조밀해집니다. (개별 타일의 물리적 화질은 200px로 항상 고정됩니다)

📋 기능 요약

가상 그리드를 나눌 조각의 단위 크기를 결정하여 가로 몇 칸, 세로 몇 칸의 모자이크를 만들지(Density)를 조정합니다.

⚙️ 동작 원리

  • 값이 작을수록 (10~15) — 타일 수가 기하급수적으로 증가 (예: 가로 192칸). 캔버스 크기가 폭증하여 OOM 경고가 발생할 수 있습니다. 모자이크가 매우 조밀해져 멀리서 보면 원본처럼 보입니다.
  • 값이 클수록 (40~60) — 타일 수 감소 (예: 가로 48칸). 빠른 처리·낮은 리소스.
💡 권장값 — 일반 전시: 20 (기본, 밸런스) / 대형 스크린(55"+): 15~18 / 근접 관람: 25~35
⚠️ 그리드 밀도 변경 시 매칭 수가 달라지므로 캐시가 초기화됩니다.

모자이크 타일이 몇 칸 들어갈지(그리드 밀도)를 결정하기 위한 가상의 해상도 기준입니다. (실제 출력 크기가 아닙니다)

📋 기능 요약

업로드된 사진을 분석할 때 사용할 '가상의 도화지' 크기입니다. 타일 크기(Tile Size)와 결합되어 모자이크의 가로/세로 칸수(Density)를 결정합니다.

📐 각 옵션 상세 (가로 칸 수)

  • 1080px — 20px 타일 기준 가로 54칸. 빠른 처리.
  • 1440px (권장) — 20px 타일 기준 가로 72칸. 속도와 디테일의 최적 균형.
  • 1920px — 20px 타일 기준 가로 96칸. 정밀한 디테일. (메모리 사용량 큼)
  • 2560px — 20px 타일 기준 가로 128칸. 극한의 디테일. (RAM 2GB+ 환경 권장)
⚠️ 그리드 밀도가 높아질수록 최종 캔버스 크기가 기하급수적으로 폭증합니다!

현재 설정으로 생성될 모자이크의 총 칸 수와 물리적 출력 크기입니다.

모자이크 가로 칸 수: -- 장
모자이크 세로 칸 수: -- 장 (가로 비율에 따라 변동)
최종 물리적 가로 해상도: -- px
⚠️ 캔버스가 너무 거대합니다! (가로 15000px 초과) 서버 다운을 막기 위해 개별 타일 화질이 강제 하향됩니다.

같은 타일이 전체 모자이크에서 최대 몇 번까지 반복 사용될 수 있는지 제한합니다.
