## 🛠️ Geometry Nodes 도미노 & 스냅 로직 ($T_{\text{domino}}$ & $T_{\text{snap}}$)

1. **도미노 시작 프레임 ($F_{\text{start}}$)**:
   - `Row 0` (첫 라인): $F = 200 + (\text{col} / 95) \times 220$ (F200~420 동안 1번 라인 질주)
   - `Row > 0` (전체 확산): $F = 420 + \left(\frac{\text{col}}{95} + \frac{\text{row}}{45}\right) \times 220$ (F420~860 동안 양방향 확산)
2. **도미노 플립 회전 ($\theta$)**:
   - $\text{prog} = \text{clamp}((f - F_{\text{start}}) / 25.0)$
   - $\text{pitch} = 75^\circ \times (1.0 - \text{prog}^{1.5})$ (서 있다가 넘어짐)
   - 살짝 어긋난 불규칙 각도: `prog < 1.0`일 때 $\pm 3.5^\circ$ 미세 회전 오차 적용
3. **충격파 스냅 정렬 ($F880 \sim 980$)**:
   - Frame 880에 마지막 조각이 안착하면서 퍼지는 원형 리플 진동을 거쳐, **Frame 980에 모든 각도가 정확히 0.0° (완벽한 2D 수평)로 찰칵! 정렬**!
